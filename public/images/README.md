# Kadhai image convention

Put storefront-ready files in `public/images/products/`. Keep the original camera/source files in the top-level `Images/` folder as an archive.

For each product slug:

- `<product-slug>-01.jpg` — primary model image
- `<product-slug>-02.jpg` — alternate model image
- `<product-slug>-garment.png` — garment-only studio image

Example: `hariyali-handloom-saree-01.webp`, `hariyali-handloom-saree-02.webp`, and `hariyali-handloom-saree-garment.png`.

Use lowercase kebab-case names with no spaces, brackets, dates, or social-media IDs. Recommended canvas: 1600 × 2000 px (4:5 portrait); minimum: 1080 × 1350 px. Use sRGB, JPG/WebP at roughly 80–88% quality for model photographs, and PNG or high-quality WebP for garment cutouts. Keep the subject centered with 8–12% breathing room so desktop and mobile crops remain safe.
